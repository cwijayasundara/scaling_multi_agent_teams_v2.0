Figure 3 · One door

Every tool call passes seven steps before it can change anything

The ordering is the design: classify and record before dispatch; re-check the epoch inside the commit transaction.

stale / expired → reject
violation → STOP TEAM
spoof → STOP · oversize → PAUSE
BLOCK → STOP · PAUSE / timeout / invalid → PAUSE
write fails → PAUSE, not dispatched
epoch moved / budget gone → no commit
action.authorized → action.committed
No generic tools exist. No SQL, HTTP, shell or Git. Anything outside the role manifest is an incident, not an error.
Fail closed. Monitor timeout (10 s), exception, invalid verdict or audit outage all pause the team. None of them executes the action.
Same path for everything. Direct, delegated, retried and resumed calls; model calls are booked by Guard.
